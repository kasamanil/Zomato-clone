# Zomato-clone
Zomato Clone is a responsive frontend replica of Zomato's food delivery platform, built with pure HTML and CSS. This static web application features a modern UI with a functional navigation bar, location-based search interface, and interactive restaurant cards displaying ratings and cuisine types Designed with mobile-first principles, the clone utilizes CSS Flexbox and Grid for seamless layout adaptation across devices, while hover animations and shadow effects enhance user engagement. The project demonstrates strong skills in UI development, responsive design implementation, and attention to detail in recreating Zomato's signature red-accented visual identity. Future enhancements could include JavaScript integration for dynamic content loading and API connectivity to display real restaurant data.
